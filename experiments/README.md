# /experiments

Scratch space for experimental work across the wizrag repo.

## Purpose

This folder exists so that tests, prototypes, spikes, and throwaway iterations have a dedicated home — separate from the stable demos in `/wizsearch/demo`, `/wizsearch/demo2`, and `/wizsearch/demo3`.

## Rules

- **Anything exploratory goes here first.** Before committing to a new architecture or demo, prototype it in `/experiments/<your-experiment-name>/`.
- **Nothing in `/experiments` is guaranteed to work or to be maintained.** Expect breakage. Expect it to be deleted without notice once the idea either graduates (moves to `/wizsearch/demoN`) or is abandoned.
- **Graduate or archive.** When an experiment proves its value, move it to a proper home under `/wizsearch/` (or wherever it belongs) and delete the scratch copy. When it fails, just delete the folder.
- **No step-by-step snapshots.** Don't create `experiment-step1/`, `-step2/`, `-step3/` directories. Use git history for that.
