What it is

WizSearch turns a body of text into a fast, semantic search engine that lives on a static web page. No backend, no database, no server — a JSON index and a little JavaScript in the browser. Each demo points the same engine at a different corpus.

How it works

Every demo accepts a ?q= parameter. Append a query to any demo URL and it loads with that search already run. Example: demo3/?q=github opens the page and immediately shows matches for github. That makes results shareable — drop a link, the other person sees what you saw.

The design has a second, more interesting property: you can drop any of these URLs into any AI — Claude, GPT, Gemini — and it will work with the collected index. The page is static, the index is public JSON, and the search is deterministic. An AI that fetches the page gets a knowledge base on the spot.

Three demos

01

The Claude Capability Validator

2,305 chunks · 2,045 skills · 67 sources · 75 topics

The biggest and most active index. Covers the full Claude ecosystem — every official Anthropic skill, MCP reference servers, and 2,000+ community servers from awesome-mcp-servers. Built so Claude itself can validate: given a task, search here and decide which skill or MCP fits.

  • 13-shard index, loaded on demand — scales to thousands of entries
  • Multi-token search with strict and loose fallback tiers
  • Up to 500 ranked results, no hard cap
  • Suggested queries seeded in the manifest
  • Source + topic facets for quick scoping
  • Shareable searches via ?q=

02

Warren Buffett · Berkshire Letters

49 letters · 1977–2025

Same engine, different corpus. Forty-nine years of Buffett's annual letters indexed as one searchable body. Ask about moats, float, capital allocation, mistakes — you get the exact passages, across every year.

  • Cross-year semantic retrieval in a single query
  • Passage-level results with clear year attribution
  • Perfect for idea-level study of long-form writing
  • Proof the engine generalizes past software documentation

03

Anthropic Agent Skills

762 chunks · 10 topics

The first prototype. Indexed Anthropic's Agent Skills documentation so it could be searched the way it should be searched. The version that proved the pattern worked, and every later demo is built on what this one taught.

  • Single-index architecture — simplest form of the engine
  • Topic-scoped browsing
  • Tight, focused corpus — good starting point to read the engine end-to-end

A small story about demo 01

Early on, I needed Claude to manage a GitHub repository on my behalf — commits, pushes, file deletions. The obvious approaches were slow and expensive in tokens.

So we searched demo 01. Somewhere in those 2,045 skills was the right one. We found it, Claude used it, and a task that had been burning minutes and tokens collapsed to seconds. I won't spoil the trick. The point is: the catalog works. You drop a question in, it hands back a capability.

That moment is the reason demo 01 exists in its current form.
