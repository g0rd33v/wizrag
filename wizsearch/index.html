What it is

WizSearch turns a body of text into a fast, semantic search engine that lives on a static web page. No backend, no database, no server — a JSON index and a little JavaScript in the browser. Each demo points the same engine at a different corpus.

How it works

Every demo accepts a ?q= parameter. Append a query to any demo URL and it loads with that search already run. Example: demo3/?q=github opens the page and immediately shows matches for github. That makes results shareable — drop a link, the other person sees what you saw.

A small story about demo 03

Early on, I needed Claude to manage a GitHub repository on my behalf — commits, pushes, file deletions. The obvious approaches were slow and expensive in tokens.

So we searched demo 03. Somewhere in those 2,045 skills was the right one. We found it, Claude used it, and a task that had been burning minutes and tokens collapsed to seconds. I won't spoil the trick. The point is: the catalog works. You drop a question in, it hands back a capability.

That moment is the reason demo 03 exists.
