What it is

WizSearch turns a body of text into a fast, semantic search engine that lives on a static web page. No backend, no database, no server — a JSON index and a little JavaScript in the browser. Each demo points the same engine at a different corpus.

How it works

Every demo accepts a ?q= parameter. Append a query to any demo URL and it loads with that search already run. Example: demo3/?q=github opens the page and immediately shows matches for github. That makes results shareable — drop a link, the other person sees what you saw.

The design has a second, more interesting property: drop any of these URLs into any AI — Claude, GPT, Gemini — and it will work with the collected index. The page is static, the index is public JSON, and the search is deterministic. An AI that fetches the page gets a knowledge base on the spot.

Three demos

01

Anthropic Agent Skills

762 chunks · 10 topics · official

The foundation. Indexes Anthropic's own Agent Skills documentation — the canonical, first-party source. This is the corpus that proved the pattern worked, and every later demo is built on what this one taught.

  • Single-index architecture — simplest form of the engine
  • Topic-scoped browsing across 10 topics
  • Tight, canonical corpus — official Anthropic material
  • Good starting point to read the engine end-to-end

02

Warren Buffett · Berkshire Letters

49 letters · 1977–2025

Same engine, different corpus. Forty-nine years of Buffett's annual letters indexed as one searchable body. Ask about moats, float, capital allocation, mistakes — you get the exact passages, across every year.

  • Cross-year semantic retrieval in a single query
  • Passage-level results with clear year attribution
  • Perfect for idea-level study of long-form writing
  • Proof the engine generalizes past software documentation
Open demo 02 Try: moat Try: float
03

The evolving Claude skills index

2,305 chunks · 2,045 skills · 67 sources · 75 topics · community-curated

The big one. Covers the full Claude ecosystem — every official Anthropic skill, MCP reference servers, and the 2,000+ community servers from awesome-mcp-servers. Grows with the community. Built so Claude itself can validate: given a task, search here and decide which skill or MCP fits.

  • 13-shard index, loaded on demand — scales to thousands of entries
  • Multi-token search with strict and loose fallback tiers
  • Up to 500 ranked results, no hard cap
  • Suggested queries seeded in the manifest
  • Source + topic facets for quick scoping
  • Shareable searches via ?q=

A small story about demo 03

Why demo 03 exists in its current form, in three steps.

01 · Problem

Slow & token-heavy

Claude needed to manage a GitHub repository on my behalf — commits, pushes, deletions. Every obvious approach was slow and expensive.

02 · Search

Ran a query on demo 03

Somewhere in those 2,045 skills was the right one. We pointed the validator at the task and let it rank.

03 · Answer

Minutes → seconds

Claude used the skill we found. A job that had been burning minutes and tokens collapsed to a few seconds.

I won't spoil the trick. The point: the catalog works. Drop a question in, it hands back a capability. That's the whole thesis.
